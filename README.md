# CSV-Transformer

CSV processing toolkit

## Features

- Easy-to-use CLI interface
- Fast and efficient processing
- Cross-platform support

## Installation

```bash
git clone https://github.com/Qyroxen/CSV-Transformer.git
cd CSV-Transformer
go build -o csv-transformer .
```

## Usage

```bash
.csv-transformer .
.csv-transformer --path ./src
```
